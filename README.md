# SageTalksNm

This is my very own self-developed automotive blog. Here I shall share my experiences on vehicles I have personally driven and also share my thoughts on recently released vehicles, my views will be purely based upon the visual appeal and information obtained via the spec sheet of the vehicles, except the ones I have extensively driven of course. 

The goal and reason so as the even have a blog site like this was not exactly to share my automotive journalism but a way to learn back-end development and web hosting. The reason I chose an automotive blog site is simply as motivation and my passion for cars and bikes.
If you do see the blog site down, it is probably cause my Laptop on which am hosting the server is turned off or am pushing out a new feature. Inconvenience is regretted.

## Features

- Create Posts
- Edit Posts
- Delete Posts
- View a particular post
- View all Posts

## Post Details

- ID
- Date
- Category
- Title
- Content

I only have a working java CRUD application which I intend to develop into a fully functioning blog site with a working database using PostgreSQL and also try and recreate this same java application in Springboot.
