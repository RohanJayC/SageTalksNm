# SageTalksNm

This is my very own self-developed automotive blog. Here I shall share my experiences on vehicles I have personally driven and also share my thoughts on recently released vehicles, my views will be purely based upon the visual appeal and information obtained via the spec sheet of the vehicle.

## Features

- Create Posts
- Edit Posts
- Delete Posts
- View a particular post
- View all Posts

## Post Details

- ID
- Date
- Category
- Title
- Content

## Future of this Project

I only have a working java CRUD application which I intend to develop into a fully functioning blog site with a working database using PostgreSQL and also try and recreate this same java application in Springboot.
